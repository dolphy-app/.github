# Security policy

If you find a security problem in Dolphy, please report it privately: open the **Security** tab of the repository and choose **Report a vulnerability**. Please don't open a public issue for it.

We will acknowledge your report, keep you updated while we investigate and credit you in the fix if you wish.

Extensions run with the rights of the app, so a vulnerability in an extension from the [catalog](https://github.com/dolphy-app/extensions) should be reported in that repository in the same way.
