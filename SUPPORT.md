# Getting help

- **A bug or a missing feature:** open an issue in the repository of the project it concerns ([app](https://github.com/dolphy-app/dolphy/issues), [courses](https://github.com/dolphy-app/courses/issues), [extensions](https://github.com/dolphy-app/extensions/issues)).
- **A question or an idea:** start a [discussion](https://github.com/dolphy-app/dolphy/discussions).
- **A security problem:** see the [security policy](SECURITY.md).
